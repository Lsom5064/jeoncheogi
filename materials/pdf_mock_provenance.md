- 확인일: 2026-10-05.

## 분석 범위

공개 자료의 실전 모의고사에는 용어 회상, 빈칸 완성, 사례 판별, 프로그래밍 출력 추적, SQL 결과 계산이 함께 포함된다. DB 이상 현상과 뷰, UML 관계, 서버 역할, 운영체제 계산, 성능 시험, 웹 공격 같은 일반 개념을 수업의 범위와 연결했다.

## 수업용 시험 구성

61-80번을 고정 순서로 출제하며 각 문항은 5점이다. 이론 10문항과 C 2, Java 2, Python 3, SQL 3문항으로 구성한다. 답안과 해설은 이 수업자료에 맞게 별도로 작성했다. 단순 숫자 치환이나 원문 문항의 전체 전재가 아니다.

- 61-62: DB 사례와 객체 식별.
- 63-64: 운영체제 계산 보강.
- 65-66: 성능 시험과 애플리케이션 서버 사례.
- 67-68: UML 관계와 SOLID 보강.
- 69-70: 웹 공격과 해시 길이 보강.
- 71-74: 새 C·Java 코드로 변수, 재귀, 인수 전달, 오버로딩 추적.
- 75-77: Python 얕은 복사·제너레이터·딕셔너리 보강.
- 78-80: 새 SQL 조건으로 NULL·JOIN·집합 연산 결과 계산.

원자료는 2020년 문서다. 이 시험은 2026년 공식 기출이나 시나공 원본 시험이 아니라 수업용 응용 시험이며, 공식 채점 기준으로 사용하지 않는다.
